# Getting started

The Configurator edits UnderstandMe settings without requiring Afutrans or a network connection.

1. Choose **Create configuration** to start with defaults in memory, or **Edit configuration** to open an existing JSON file.
2. Use **Translation providers** to register a backend, and **Dictionary storages** to configure localization storage.
3. Choose **Validate draft** before **Review & Save**.
4. Changes are written only after you explicitly confirm Save. Leaving an edited configuration asks whether to discard changes.

The Configurator UI can be English or Czech. This initial offline help is authored in English. Press Esc or choose Back to return; opening Help does not modify the draft.

# Toolroom utilities, ownership and boundaries

Toolroom is for executable developer/maintenance workflows rather than the reusable core business models of another family. For example, the WhenItFails error schema and runtime belong to [WhenItFails](../../../WhenItFails/README.md), while its catalog editor [Setter](../../WhenItFails/Setter/README.md) belongs to Toolroom.

Other tools include [public API comparison](../../WhenItFails/PublicApiComparer/README.md) and [release validation](../../WhenItFails/Release/README.md). These tools have separate documentation and can use SeeMe console presentation without imposing that UI dependency on the core error library.

No umbrella Toolroom runtime NuGet package is implied by this folder.

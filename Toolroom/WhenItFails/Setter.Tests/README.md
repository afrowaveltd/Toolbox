# Toolroom.WhenItFails.Setter.Tests

xUnit regression suite for the [Setter CLI](../Setter/README.md), including command parsing, safe catalog edits, output modes, backups, schema validation and automation use cases.

```bash
dotnet test Toolroom/WhenItFails/Setter.Tests/Afrowave.Toolbox.Toolroom.WhenItFails.Setter.Tests.csproj -c Release
```

See [Testing and CI](../Setter/Docs/Testing%20and%20CI/en.md), [test documentation](Docs/Testing/en.md) and [status](IMPLEMENTATION_STATUS.md). Tests are not released as a standalone package.

# Essentials.Tests

.NET 10 xUnit regression suite for [Essentials](../Essentials/README.md): results/responses, metadata, issues, diagnostics, guards, extensions, interfaces and value objects.

```bash
dotnet test Essentials.Tests/Essentials.Tests.csproj -c Release
```

The suite verifies Essentials behavior but is **not a NuGet package**. See [Testing conventions](Docs/Testing/en.md) and [implementation status](IMPLEMENTATION_STATUS.md).

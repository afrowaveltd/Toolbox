# AJIS / A2 scope in Toolbox

The existing `Ajis/DESIGN_NOTES.md` provides architecture exploration for AJIS/A2, including serialization and transport ideas, potential low-resource profiles and legacy interoperability. It should not be mistaken for a compiled AJIS2 library or a public NuGet release in this repository.

The previous AJIS implementation is in the separate [Ajis.Dotnet](https://github.com/afrowaveltd/Ajis.Dotnet) repository. Any new Toolbox implementation must first define the actual project, acceptance tests and compatibility guarantees, then update the implementation status as work is committed.

The notes are intentionally preserved rather than rewritten from shorthand summaries.

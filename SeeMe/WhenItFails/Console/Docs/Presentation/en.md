# Console output adapter

This independent project contains `ConsoleIssueShow`, `ConsoleValidationResultShow`, `ConsoleShowTheme`, `ConsoleShowOptions` and `ConsoleMarkupHelper`. It is built against .NET 10 and Spectre.Console 0.57.2, and references the [WhenItFails project](../../../../../WhenItFails/README.md).

The rendering adapter is consumed by the [WhenItFails Setter executable](../../../../../Toolroom/WhenItFails/Setter/README.md); catalog validation and mutation belong to WhenItFails / Setter rather than SeeMe. UI details are not part of the Essentials result contract.
